# TikTok Manager Bot

🤖 **Telegram-бот для автоматизации и управления фермой аккаунтов TikTok.**

Позволяет централизованно управлять профилями (био, никнейм, аватарка), загружать видео с обложками и расписанием, а также накручивать живую активность (лайки и комментарии с защитой от спам-фильтров и автоматическим решением капчи).

---

## 🚀 Основные возможности

* 👥 **Мультиаккаунтность**: Подключение неограниченного числа аккаунтов по Cookies (JSON/Netscape).
* 🌐 **Поддержка Прокси**: Привязка индивидуальных HTTP/SOCKS5 прокси к каждому профилю.
* ✏️ **Управление профилями**:
  * Смена Никнейма и Био (с обработкой лимитов редактирования TikTok).
  * Загрузка аватарки с автоматической обрезкой в модалке TikTok (Crop Modal).
* 🎬 **Публикация видео**:
  * Загрузка через веб-студию TikTok Studio.
  * Описание с тегами и упоминаниями.
  * Настраиваемая задержка между публикациями (антибан).
* ❤️💬 **Взаимодействие (Лайки и Комментарии)**:
  * Одиночный и массовый режим (по всем аккаунтам).
  * Таргетинг по ссылке на видео или по ссылке на профиль (автовыбор последнего видео).
  * Ротация комментариев (случайный выбор из списка через `;`).
  * Точное определение статуса лайка по стандарту WAI-ARIA.
  * Отправка скриншота-доказательства выполненного действия в Telegram.
* 🧩 **Обход защиты и капчи**:
  * Встроенная интеграция с CapSolver (автоматическое решение 3D-вращения и пазлов-слайдеров).
  * Защита от TicketGuard (код 1104) через реальный бинарник Google Chrome.

## 🛠 Быстрый старт (Локально / Разработка)

### 1. Клонирование и виртуальное окружение:
```bash
git clone <URL_РЕПОЗИТОРИЯ>
cd tiktok_bot

python -m venv venv
# Windows:
.\venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate
```

### 2. Установка зависимостей:
```bash
pip install -r requirements.txt
playwright install chromium

# Если запускаете на Linux / Ubuntu сервере (ОБЯЗАТЕЛЬНО для работы Chromium):
playwright install-deps
```

### 3. Формат Cookies для добавления аккаунтов:
Бот поддерживает любые популярные форматы:
1. **JSON-массив** — экспорт через расширение Chrome `Cookie-Editor` (кнопка Export -> Export as JSON).
2. **Netscape** — файл `cookies.txt` или текст из любых магазинов аккаунтов.
3. **Строка заголовка** — `sessionid=xxxx; sid_tt=yyyy;`
4. **Один токен** — просто значение `sessionid` из cookies.

### 3. Настройка конфигурации:
Создайте файл `.env` на основе `.env.example`:
```ini
BOT_TOKEN=ваш_токен_бота_в_telegram
ADMIN_IDS=ваш_telegram_id
CAPSOLVER_API_KEY=ваш_ключ_capsolver
DATABASE_PATH=data/bot.db
```

### 4. Запуск бота:
```bash
python main.py
```
